## 백로그 (MVP 이후)
MVP 범위 밖 아이디어는 여기에 추가한다.

- 에이전트 상태 감지: Claude Code hooks(`Stop`, `Notification`) / Codex `notify` → pane 헤더 `작업 중 / 입력 대기 / 완료` + Windows 토스트
- hook 없는 CLI용: 출력 무변화 N초 휴리스틱
- 셸 안에서 직접 실행한 프로그램 감지 (포그라운드 프로세스) → 탭 auto-rename · agent pane 인식
- 다른 세션 · 탭에서 출력이 쌓이면 사이드바 활동 표시 · 알림
- 한도 임박(90%) Windows 토스트
- Antigravity 한도 출처 (M2-04 조사에서 못 찾은 경우)
- 커맨드 팔레트 (`Ctrl+Shift+P`), 스니펫 · 자주 쓰는 명령
- detach 모드: 백그라운드 데몬이 PTY 보유 → 앱을 꺼도 세션 유지
- 스크롤백 검색 UI, pane 출력 저장
- 자동 작업 후속: 작업별 타임아웃 · 완료/실패 Windows 토스트 · 실패 시 재시도 · 로그 검색 · WSL 셸 · 앱 꺼진 동안 예약(detach 데몬 필요)
- 모바일 접속 QR 코드 표시, 폰에서 새 pane 만들기, 화면 복원 정확도(serialize addon)
