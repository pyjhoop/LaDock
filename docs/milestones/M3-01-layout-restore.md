# M3-01 레이아웃 저장 · 복원

- 마일스톤: M3 복원·설정 · 의존: M1-01, M2-02
- 참고: [architecture.md › 데이터 모델](../architecture.md#데이터-모델) (`AppState`), [› 저장 위치](../architecture.md#저장-위치)

## 목표
앱을 껐다 켜도 세션 · 탭 · 분할 구조 · 작업 폴더가 그대로 돌아온다.

## 할 일
- [ ] `state_save`: `%APPDATA%\LaDock\state.json`에 저장 — 변경 후 1초 디바운스, 앱 종료 직전 한 번 더
- [ ] 저장 내용: 세션 → 탭 → 분할 트리 · 비율 · 활성 세션/탭 · 포커스 · pane별 `{ profileId, cwd, command, args, kind, provider }`
- [ ] `state_load`: 시작할 때 같은 구조로 **새 프로세스를 띄워 복원** (프로세스 자체는 복원 안 됨)
- [ ] AI pane 복원: "이전 대화 이어서 열기" 선택지 → `claude -c` / `agy -c`, 아니면 새로 시작
- [ ] 저장 파일이 깨졌거나 버전이 다르면: 백업해 두고 기본 세션으로 시작 + 알림
- [ ] 파일에 `version` 필드를 두고 마이그레이션 자리 만들기
- [ ] 복원할 cwd가 사라졌으면 홈 폴더로

## 완료 기준
- [ ] 3세션 × 여러 탭 × 분할을 만든 뒤 재시작하면 같은 구조 · cwd로 열림
- [ ] AI pane 이어하기가 동작
- [ ] state.json을 일부러 망가뜨려도 앱이 정상 시작
