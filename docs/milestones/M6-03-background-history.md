# M6-03 자동 작업 — 백그라운드 실행 · 실행 기록 페이지

- 마일스톤: M6 자동 작업 · 의존: M6-01
- 참고: [architecture.md](../architecture.md) `RunRecord` · `task_run_*` IPC

## 목표
작업이 pane을 만들지 않고 **창 없는 백그라운드 프로세스**로 돌고, 출력이 로그로 남아 **전용 페이지**에서 다시 볼 수 있다.

## 할 일
- [x] Rust `task_run.rs`: 창 없이 spawn(`CREATE_NO_WINDOW`), stdout+stderr를 `task-logs/<runId>.log`로 (2MB 상한), 종료 이벤트 `task://exit`, 프로세스 트리 중지(`taskkill /T /F`), 앱 종료 시 정리
- [x] 실행 기록 `task-history.json` (최근 200건, 넘치면 오래된 것부터 로그 파일까지 삭제), 앱이 꺼져 중단된 'running' 기록은 '오류'로 정리
- [x] AI 작업: 공식 CLI 비대화형 — Claude · agy `-p <프롬프트>`, Codex `exec <프롬프트>`(미설치라 미검증). 구독 전용이면 API 키 환경변수 제거
- [x] 사이드바 카드: 마지막 실행 상태(◌ 실행 중 · ✓ · ✗ · ■ · !), 실행 중에는 ▶가 ■(중지)로
- [x] **기록 페이지**(사이드바 자동 작업 절의 ☰): 왼쪽 실행 목록(작업 필터 · 모두 지우기), 오른쪽 상세(상태 · 소요 시간 · 종료 코드 · 실행 내용 · 로그), 실행 중 로그는 1초마다 갱신하며 맨 아래를 따라감, 중지 · 다시 실행 · 기록 지우기 · 로그 복사
- [x] 로그의 ANSI 색상 시퀀스 제거
- [x] 한글 출력: PowerShell `OutputEncoding` UTF-8, cmd `chcp 65001`, Python `PYTHONIOENCODING`
- [x] PowerShell 종료 코드: 마지막 네이티브 명령의 코드를 그대로, cmdlet 실패는 1

## 완료 기준
- [x] Rust 테스트: 실제 `cmd.exe`로 stdout · stderr · 종료 코드 캡처, 2MB 절단 안내, 실행 id 경로 탈출 차단
- [x] pwsh · cmd로 한글 출력과 종료 코드(7)가 맞게 나옴 (node 파이프로 확인)
- [x] 실제 앱에서 command · script · ai 작업이 백그라운드로 돌고 기록 페이지에서 로그가 보임
- [x] 실행 중 중지 · 앱 종료 후 재시작 시 기록이 남고 'running'이 '오류'로 정리됨

## 작업 기록
- 2026-10-19 사용자 결정: 실행은 **전부 백그라운드**(AI 포함), 기록은 **전용 페이지**. 이에 맞춰 CLAUDE.md 절대 규칙의 "AI는 pane 안에서만"을 "자동 작업에 한해 공식 CLI의 비대화형 플래그를 백그라운드로 실행해도 된다"로 고쳤다. 토큰 · 비공개 API 금지는 그대로.
