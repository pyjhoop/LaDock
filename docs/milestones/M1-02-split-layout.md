# M1-02 분할 레이아웃 렌더링

- 마일스톤: M1 세션·탭·pane · 의존: M1-01, M0-04(렌더러 정책)
- 참고: `design-mvp.html`의 `nodeEl`, `paneEl`, `renderLayout`, `.split`, `.divider`

## 목표
분할 트리를 화면에 그리고, 마우스로 리사이즈 · 포커스 · 줌 · 닫기를 할 수 있다.

## 할 일
- [ ] 트리 재귀 렌더링: split = flex(row/col), 자식 비율 = `flex: ratio 1 0`
- [ ] 6px 분할선 드래그 (pointer capture) → 비율 갱신 → 끝나면 `pty_resize`
- [ ] 클릭으로 포커스, 포커스된 pane 테두리 강조
- [ ] 줌: 포커스된 pane만 전체 표시, 트리는 유지
- [ ] pane 헤더 버튼 연결: 좌우 분할 / 상하 분할 / 줌 / 닫기
- [ ] **다른 탭 · 세션의 터미널을 언마운트하지 않음** — `display:none`으로 숨기고 다시 보일 때 `fit()`
- [ ] M0-04에서 정한 렌더러 정책 적용 (예: 보이는 pane만 WebGL)

## 명세
- 줌 상태에서 분할하면 줌 해제
- 드래그 중에는 레이아웃만 바꾸고, PTY 리사이즈는 드래그가 끝날 때 한 번

## 완료 기준
