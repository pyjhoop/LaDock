# M6-02 자동 작업 — 예약 실행

- 마일스톤: M6 자동 작업 · 의존: M6-01, M6-03

## 목표
작업에 시간 규칙을 붙여, 앱이 켜져 있는 동안 정해진 때 자동으로 백그라운드 실행한다.

## 할 일
- [x] 예약 규칙 3가지: `none`(수동) · `daily`(시각 `HH:MM` + 요일) · `interval`(N분마다)
- [x] 스케줄러: 앱 기동 후 20초마다 확인해서 때가 된 작업을 실행 (`isDue` 순수 함수)
- [x] 같은 작업의 이전 실행이 아직 돌고 있으면 겹쳐 실행하지 않고 다음 틱에 다시 본다
- [x] 마지막 실행 시각(`lastRunAt`)을 `tasks.json`에 기록
- [x] 등록 팝업에서 규칙 편집 · 예약 켜기/끄기

## 명세
- **앱이 꺼져 있던 동안의 예약은 보충 실행하지 않는다.** daily는 예정 시각 + 5분 안에서만 실행, 놓치면 다음 때로 넘어간다
- interval은 `lastRunAt`(없으면 앱을 켠 시각) 기준으로 N분이 지나면 실행. 최소 1분
- 창을 닫으면 트레이로 숨고 앱은 계속 도는 구조라 예약도 계속 동작한다. 트레이 종료 시에는 멈춘다 (실행 중이던 작업도 함께 종료)
- 예약 실행은 화면에 아무것도 띄우지 않는다. 결과는 기록 페이지와 사이드바 카드의 상태 표시(✓ ✗)로 본다

## 완료 기준
- [x] `isDue` 단위 테스트: daily 시각 · 요일 · 유예 5분 · 중복 방지, interval 경계
- [x] 실제 앱에서 1분 간격 작업이 백그라운드로 돌고 기록이 쌓임
