# M6-01 자동 작업 — 프리셋 (명령 · 스크립트 · AI 프롬프트)

- 마일스톤: M6 자동 작업 · 의존: M2-02, M3-02
- 참고: 데이터 모델은 [architecture.md](../architecture.md) "자동 작업"

## 목표
자주 하는 일을 **작업(Task)** 으로 저장해 두고, 사이드바 ▶ 한 번 / `Ctrl+B g` + 숫자로 실행한다. 실행 방식(백그라운드 · 기록)은 [M6-03](M6-03-background-history.md).

## 할 일
- [x] 작업 종류 3가지: `command`(셸 한 줄) · `script`(파일 경로 + 인자) · `ai`(provider + 프롬프트)
- [x] 작업 저장 `%APPDATA%\LaDock\tasks.json` (`tasks_load` / `tasks_save`, settings와 같은 방식)
- [x] **왼쪽 사이드바 "자동 작업" 절**: 작업 카드 목록 · ▶ 실행 · 카드 클릭 = 편집 · `+` 등록 팝업 (설정 페이지가 아님)
- [x] 등록 · 편집 팝업(`TaskDialog`): 이름 · 종류 · 내용 · 셸 · 작업 폴더 · 예약 · 삭제. 바깥 클릭으로는 안 닫힘 (Esc · 취소)
- [x] 실행 팔레트 `Ctrl+B g`: 숫자 키로 작업 실행
- [x] 순수 함수(셸 인자, 스크립트 한 줄, 파싱)는 Vitest로 검증

## 명세
- 셸 한 줄: pwsh · powershell · cmd · bash. 그 외 셸(WSL 등)은 "지원하지 않는 셸" 안내
- script 한 줄: `.py` → `python '<경로>' 인자`, `.js` → `node`, `.sh` → `bash`, 나머지(`.ps1` `.bat` `.cmd` `.exe`) → `& '<경로>' 인자`
- cwd가 비어 있으면 실행 순간 포커스 pane의 현재 폴더를 쓴다 (M2-02와 동일)
- AI 작업은 구독 전용 · 권한 생략 · provider 추가 인자 설정을 기존 AI 실행과 똑같이 따른다
