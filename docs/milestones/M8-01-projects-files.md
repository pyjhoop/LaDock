# M8-01 프로젝트 사이드바 · git 파일 패널

- 마일스톤: M8 사이드바 개편 · 의존: M1-04 (세션·탭 UI), M7-01 (에이전트 감지)
- 참고: [architecture.md › 공용 타입](../architecture.md)

## 목표
Orca처럼 좌측을 **프로젝트(폴더) 목록**으로 바꾸고, 우측에 **git 저장소 폴더 구조 · 파일 보기**를 둔다.

## 결정 (2026-10-26, 사용자 요청)
- UI의 "세션"은 **프로젝트**로 바꾼다. 내부 타입 · IPC 이름(`Session`, `newSession` …)은 그대로 둔다 (저장 파일 호환).
- 추가 버튼은 선택지를 준다: **폴더 선택해서 추가** / **기본 폴더에서 빠르게 시작**(폴더 없이 셸 기본 위치에서 바로 시작, 이름 "빠른 시작"). 키보드 `Ctrl+B C`는 폴더 선택.
- `Session.cwd?`가 프로젝트 폴더. 추가할 때 **폴더 선택 창**(`tauri-plugin-dialog`)으로 고르고, 이름은 폴더 이름. 취소하면 추가하지 않는다. `Ctrl+B C` · 트리 오버레이 `C`도 같은 흐름. 폴더 없이 만든 기존 세션은 포커스된 pane의 폴더를 따른다.
- 실행 중인 에이전트는 별도 섹션이 아니라 **각 프로젝트 하단**에 "에이전트 N" 접이식 목록으로 둔다 (기본 펼침, 프로젝트별로 접기). 프로젝트 행에 개수 배지.
- 우측 패널은 **git 없이도** 항상 쓸 수 있다 (2026-10-26 변경). 루트는 활성 프로젝트 폴더가 git 저장소 안이면 저장소 루트, 아니면 프로젝트 폴더 자체이고, 폴더가 없으면(빠른 시작) 홈이다 (`fs_root`). 지연 로딩 폴더 트리(`.git` 숨김), git이면 브랜치 표시, 새로고침. 파일을 누르면 작업 영역 위에 읽기 전용 뷰어(줄 번호, 512KB 제한, 바이너리는 안내만, Esc로 닫기).
- 패널은 타이틀바 버튼으로 접었다 펼치고, 왼쪽 가장자리를 끌어 폭을 200~640px로 조절한다 (더블클릭 = 기본 260px, 폭은 localStorage에 기억). 창이 wide(≥1024)일 때만 보이고 폰 원격 화면에서는 쓰지 않는다.
- 탭은 좌측 사이드바에 따로 나열하지 않는다. 탭 줄은 타이틀바가 아니라 **가운데 작업 영역 바로 위**로 옮겨 가운데 창과 폭을 맞춘다 (타이틀바에는 프로젝트 버튼만 남는다). 사이드바 프로젝트 아래에는 경로와 에이전트만 둔다 (2026-10-26).
- git 저장소면 우측 패널에 **폴더 / 로그** 탭과 git 상태 요약이 붙는다 (2026-10-26). 요약: 푸시 필요(↑) · 풀 필요(↓) · 갈라짐 · 업스트림 없음 · 변경/스테이지/새 파일/충돌 수. git CLI(`status --porcelain=v2`, `log`)를 읽기 전용으로 실행하고 10초마다 갱신한다. 풀 필요 여부는 **마지막 fetch 기준**이라 `원격 확인` 버튼(`git fetch`, 파일은 안 바뀜)을 눌러 최신화한다 — 자동 fetch는 하지 않는다. 로그는 현재 HEAD 기준 50개씩 `더 보기`. 커밋을 누르면 **새 탭**에 변경 내용 보기(`PaneSpec.kind: 'diff'`, `DiffPane`)가 열린다 — 커밋 메시지 · 파일 목록(+/− 개수, 클릭하면 이동) · 왼쪽 파일 목록(상태 M/A/D/R · +/−)과 오른쪽 **선택한 파일 하나만** 보는 unified diff — 한 pane에 다 이어 붙이면 길어져서 나눴다. pane이 640px보다 좁으면 목록이 위로 올라간다. 메시지 본문은 접어 둔다. 줄 번호, 추가/삭제 색(줄 번호, 추가/삭제 색). `git_show`(Rust)가 patch를 주고 `parseDiff`(TS)가 나눈다. 읽기 전용(편집 · 스테이징 없음), 머지 커밋은 첫 부모 기준, 3MB 초과는 잘라서 안내, 폰 원격 화면에서는 안내만 표시. 이 결정으로 CLAUDE.md의 "diff 뷰어 범위 밖"을 풀었다 (2026-10-26).
- 프로젝트를 모두 제거하면 `main`을 만들지 않고 **빈 시작 화면**(프로젝트 추가 · 작업 추가 · 빠른 시작)이 나온다 (2026-10-26). 첫 실행도 빈 화면. 이 상태에서 AI 실행 팔레트로 pane을 열면 "빠른 시작" 프로젝트가 만들어진다. 탭 · 분할 키는 무시.
- 프로젝트를 **묶음 폴더**로 정리한다 (2026-10-29, 사용자 요청). 프로젝트 추가(+) 메뉴의 "묶음 폴더 만들기"로 만들고, 폴더 우클릭 → 이름 변경 · 하위 폴더 추가 · 제거(안의 항목은 위로), 프로젝트 우클릭 → "폴더로 이동 / 꺼내기". 폴더는 최대 **3단계**까지 중첩. 순수 UI 분류라 세션 저장 파일은 건드리지 않고 localStorage(`ladock.projectFolders`)에 둔다 (`groups.ts`). 드래그 이동은 아직 없다.
- 좌측 사이드바 폭은 오른쪽 가장자리를 끌어 200~420px로 조절 (더블클릭 = 252px, localStorage `ladock.sidebarWidth`). 드로어 모드에서는 고정 폭.
- 파일 접근은 Rust `files.rs`에서 읽기 전용 + 저장소 밖 경로(`..`, 절대 경로, 심볼릭 링크 탈출) 차단.
- 범위 밖(백로그): git 변경 표시 · diff, 검색, 편집, 구문 강조, 우측 패널 폭 조절.
