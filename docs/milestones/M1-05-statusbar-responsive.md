# M1-05 상태바 · 반응형

- 마일스톤: M1 세션·탭·pane · 의존: M1-04
- 참고: `design-mvp.html`의 `renderStatus`, `renderChips`, `@media (max-width: 1023px / 639px)`, `@container`

## 목표
상태바로 현재 위치를 보여주고, 창을 줄여도 쓸 수 있게 레이아웃을 바꾼다.

## 할 일
- [ ] **상태바 (왼쪽 → 오른쪽)**: `PREFIX` 표시 · 세션(색 점 + 이름) · 탭 목록 `1:dev* 2:build` · `pane 1/3`(+`ZOOM`) · cwd · (빈 공간) · 단축키 힌트 · **[한도 표시 자리 — M2-05]** · `?`
- [ ] **반응형** — 아래 표
- [ ] 스택 모드: 포커스된 pane 하나만 표시 + 위쪽 pane 칩으로 전환, 포커스 이동 키는 칩 순서대로 순환
- [ ] 드로어: 640–1023px에서 사이드바는 ☰로 여닫는 오버레이 + 배경 클릭으로 닫힘
- [ ] pane 헤더 container query: 좁으면 cwd → 활동 글자 → 보조 버튼 순서로 숨김

## 반응형 기준

| 창 폭 | 레이아웃 |
| --- | --- |
| ≥ 1024px | 사이드바 고정 + 분할 pane 전부 표시 |
| 640–1023px | 사이드바 = 오버레이 드로어, 분할 그대로, 상태바 cwd · 일부 힌트 숨김 |
| < 640px | 스택 모드 + pane 칩, 창 버튼 · 브랜드 글자 · 단축키 힌트 · 탭 목록 숨김 |

## 완료 기준
- [ ] 세 구간 모두에서 레이아웃이 깨지지 않고 가로 스크롤이 생기지 않음
- [ ] 스택 모드에서 칩과 키보드로 모든 pane에 갈 수 있음
- [ ] 구간을 넘나들며 창 크기를 바꿔도 터미널 출력이 유지됨
