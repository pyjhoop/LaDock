## 반응형 기준

| 창 폭 | 레이아웃 |
| --- | --- |
| ≥ 1024px | 사이드바 고정 + 분할 pane 전부 표시 |
| 640–1023px | 사이드바 = 오버레이 드로어, 분할 그대로, 상태바 cwd · 일부 힌트 숨김 |
| < 640px | 스택 모드 + pane 칩, 창 버튼 · 브랜드 글자 · 단축키 힌트 · 탭 목록 숨김 |

## 작업 기록

- 2026-10-19 구현: `StatusBar`, `PaneChips`, `ui.ts`의 `mode`(wide/mid/narrow, `window.innerWidth` 기준) · `drawerOpen`. 스택 모드는 줌과 같은 방식(포커스 pane 외 `display:none`)이라 숨은 터미널과 PTY는 그대로 유지된다. 스택 모드의 포커스 이동(←↑→↓)은 `keys.ts`에서 칩 순서로 순환.
- 기존 떠 있던 `PREFIX` 배지는 상태바 `PREFIX` 칩으로 대체해 제거.
- pane 헤더에는 아직 "활동 글자"가 없어 container query는 cwd → 분할 버튼(`.opt`) 순서로만 숨김.
- 한도 표시 자리는 주석으로만 남김 (M2-05).
- `pnpm check` 통과. 세 구간 실제 화면 확인(가로 스크롤 · 칩 전환 · 리사이즈 시 출력 유지)은 `pnpm tauri dev`에서 아직 못 해서 완료 기준은 체크하지 않음.
- 2026-10-19 사용자가 `pnpm tauri dev`에서 직접 확인해 완료 기준 통과.
